# My-first-app 🐞 こんちゅうずかん

日本でよく見られる昆虫を中心に集めた、2歳児向けの「こんちゅうずかん(昆虫図鑑)」Webアプリです。
Wikimedia Commons の実写真と、ひらがな中心のやさしい説明で、小さな子どもが指でタップして楽しめます。

## 概要

- 対象年齢: 2歳前後の子ども(保護者と一緒に見る想定)
- 日本でよく見られる昆虫 50種 + 日本にはいないが人気・美麗な昆虫 15種、あわせて 65種類を収録
- すべて Wikimedia Commons のフリーライセンス写真を使用(出典・ライセンスは「📷 しゃしんについて」から確認可能)
- ビルド不要のシンプルな静的サイト(HTML / CSS / JavaScript のみ)

## 起動方法

インストール作業やビルドは不要です。以下のどちらかの方法で開いてください。

### 方法1: ファイルを直接開く

`index.html` をブラウザにドラッグ&ドロップ、または直接開くだけで動作します。

### 方法2: ローカルサーバーで開く(推奨)

読み上げ機能などをより安定して使いたい場合は、簡易サーバーを立てて開いてください。

```bash
npx serve .
# または
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000`(使用したツールに応じたURL)にアクセスします。

## 主な機能

- **昆虫カード一覧**: 「にほんの むし」「せかいの むし」の2セクションに分けて、実写真のカードが並びます。
- **タップで詳細表示**: カードをタップすると、大きな写真と昆虫の名前・学名・やさしい説明が表示されます。
- **音声読み上げ**: 詳細画面を開くと自動で名前と説明を読み上げます(ブラウザの音声合成機能を使用)。「🔊 よんで きかせて」ボタンで何度でも聞き直せます。
- **写真クレジット**: フッターの「📷 しゃしんについて」から、各写真の撮影者・ライセンス・出典リンクの一覧を確認できます。
- **スマホ・タブレット対応**: 大きなタップ領域とレスポンシブレイアウトで、小さな子どもでも操作しやすい画面になっています。

## 昆虫を追加したい場合

`script.js` の `INSECTS` 配列に、`id` / `name` / `scientificName` / `region`("japan" か "world") / `desc` / `image`(`url` / `license` / `author` / `sourcePage`)を持つオブジェクトを追加するだけで新しい昆虫を増やせます。画像は Wikimedia Commons など再配布可能なライセンスの写真を使ってください。
